# Create and organize collections

Collections hold your HTTP requests in a nested folder tree in the left sidebar.

## Create a collection

1. Open the **Collections** panel on the **left rail** (folder icon).
2. Click **New (+)** in the header above the tree.
3. Click **Collection** in the popup grid.
4. Type a name and press **Enter**, or click away to accept the default name.

## Create an HTTP request

1. Click **New (+)** in the collections header.
2. Click **HTTP Request**.
3. A new request appears under the selected collection or folder (or at the root).
4. Double-click the request to open it in the centre area.

## Rename an item

1. Right-click a collection, folder, or request in the tree.
2. Choose **Rename**.
3. Edit the name inline and press **Enter**.

You can also slow-double-click a tree item to rename it.

## Reorder with drag and drop

Drag a collection, folder, or request in the tree and drop it on a new parent or
between siblings. The new order is saved automatically.

## Duplicate a request

1. Right-click a saved request in the tree.
2. Choose **Duplicate**.
3. A copy appears next to the original (including saved responses and assertions).

## Search the tree

Type in the **search** field in the collections header to filter visible items by name.
