# Environments

Environments are named sets of variables you activate workspace-wide. They drive
`{{variable}}` substitution in URLs, headers, bodies, and scripts.

| Page | Description |
|------|-------------|
| [Variables](variables.md) | Create environments, activate, and use `{{var}}` |

## Quick start

1. Open the left rail **Environments** flyout.
2. Click **Manage** (or an empty-state link) to open the environment editor.
3. Add key/value rows and save.
4. Click **Set active** on the environment you want for sends and the collection runner.

The active environment name appears on the environment row. Use **Clear** to stop substituting environment variables.
