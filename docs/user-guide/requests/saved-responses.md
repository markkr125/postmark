# Saved responses

Save a live response as a named example attached to a request. Use saved responses
as documentation, mocks, or regression references.

## Save a response

1. Send a request so the **Response** viewer shows a live result.
2. Click **Save Response** in the response toolbar (only available for live responses).
3. Enter a name when prompted.

The example is stored with status, headers, body, and a snapshot of the original request.

## Browse saved responses

1. Open the request tab you care about.
2. On the **right rail**, click the **Saved responses** icon.
3. Select an entry in the list — details appear in the flyout (headers, body, metadata).
4. Use the search field to filter by name or body text.

## Manage examples

From the saved-responses flyout (with an entry selected):

| Action | How |
|--------|-----|
| Rename | Use the rename control in the panel header |
| Duplicate | **Duplicate** — creates a copy with a new name |
| Delete | **Delete** — removes the example permanently |

Saved responses are read-only in the flyout. To send again, use the live request editor and **Send**.
