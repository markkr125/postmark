# Script snippets

Insert reusable script fragments from a palette instead of typing boilerplate.

## Open the snippet palette

1. Open the **Scripts** tab (request, folder, collection, or local script).
2. Click **Snippets** in the script toolbar.
3. Search or browse categories (Workflows, Variables, Tests, Pre-request helpers, and user categories).

4. Click a row to insert at the cursor (read-only insert — the palette does not edit your collection).

## User snippets

Create your own snippets for repeated patterns:

1. In the script editor, select code (optional).
2. Right-click → **Save as snippet…** (or use the equivalent menu action).
3. Choose language, category, and name.

Manage user snippets from the left **Snippets** flyout (under local scripts):

- Browse by language → category → snippet
- Right-click for edit, rename category, or delete

User snippets appear with accent styling in the palette.

## Sidebar snippets flyout

The left rail **Snippets** section lists all user snippets in a tree. Use it to review and maintain your library; insertion still happens from the editor **Snippets** button.
