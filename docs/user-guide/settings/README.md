# Settings

Open **File → Settings…** or press **Ctrl+,** to change appearance, tabs, scripting runtimes, history retention, AI, and private package registries.

Settings use a category tree on the left and a detail page on the right.

| Page | Settings category |
|------|-------------------|
| [Appearance](appearance.md) | Theme and colour scheme |
| [Tabs](tabs.md) | Request tab behaviour and session restore |
| [Scripting runtimes](scripting-runtimes.md) | Deno, Python, LSP, format on save |
| [History](history.md) | Send history retention and bodies |
| [AI](ai/README.md) | Models, agents, budgets |
| [Private packages](private-packages/README.md) | npm, JSR, PyPI credentials |
