# Appearance settings

Control light/dark theme and accent styling for the whole application.

## Steps

1. Open **File → Settings…** (**Ctrl+,**).
2. Select **Appearance** in the category tree.
3. Choose **Theme style** (e.g. follow system, light, or dark).
4. Choose **Colour scheme** if multiple palettes are available.
5. Click **Apply** or **OK** to save.

Changes apply immediately to the main window, editors, and sidebars.
