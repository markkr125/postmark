# Tab settings

Control how request tabs open, wrap, limit, and restore between sessions.

## Steps

1. Open **File → Settings…** → **Tabs**.

## Common options

| Setting | Effect |
|---------|--------|
| Preview tabs | Single-click opens a temporary tab replaced on next preview |
| Compact tab labels | Shorter names on tab chips |
| Duplicate name paths | Show folder path when two tabs share a name |
| Wrap mode | **Multiple rows** vs **single row** tab deck |
| Tab limit | Maximum open tabs; policy for closing unchanged or unused tabs |
| Activate on close | Which tab becomes active when you close the current one |

## Session restore

Postmark can reopen tabs from your last session on launch. Tab order and the active tab are restored after the collection tree finishes loading.

Draft tabs may restore with unsaved editor content when session data includes a snapshot.
